Why Apptainer is needed here
----------------------------

Running ./ldopt_bignoise.sh directly on the host failed because uv attempted to
resolve onnxruntime==1.23.2 for a host platform without a compatible wheel.

Running the existing .venv directly on the host also failed because its installed
onnxruntime binary requires GLIBC_2.27, while the host provides an older glibc.

The Apptainer image uses Ubuntu 24.04, so the existing project environment works
there and ./ldopt_bignoise.sh can complete.
